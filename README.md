# Khwab Kalra — Personal Site

Single-page continuous-scroll personal site. Drop this whole folder onto https://app.netlify.com/drop to deploy in 30 seconds.

## Files
- `index.html` — the site
- `resume.pdf` — **drop your resume PDF here** (same folder) before deploying
- `_headers` — Netlify config: cache headers + security
- `netlify.toml` — Netlify build settings (works with plain static files, no build step)

## Quick deploy (Netlify Drop)
1. Put `resume.pdf` in this folder
2. Open https://app.netlify.com/drop
3. Drag this folder onto the page
4. Claim the URL it gives you, rename to `khwab-kalra`
